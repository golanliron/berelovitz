# חבילת העיצוב של Berelowitz Family Foundation

החבילה מיועדת להעברה ישירה ל-Claude Code לצורך בניית האתר.

## מה נמצא בחבילה

### assets/originals

- `berelowitz-logo.png` — הלוגו המקורי. אין לשנות או לייצר מחדש.
- `barry-berelowitz.png` — התמונה המקורית של ברי ברלוביץ ז״ל. אין לערוך את פניו.

### assets/designs

- `homepage-with-barry.png` — הסקיצה המרכזית והקובעת לעמוד הבית.
- `design-system-board.png` — לוח השפה: צבעים, טיפוגרפיה, כפתורים ורכיבים.
- `homepage-logo-led.png` — כיוון מינימליסטי המבוסס על הלוגו.
- `our-work-page.png` — דוגמה לעמוד תחומי פעילות.
- `about-page.png` — דוגמה לעמוד אודות.
- `homepage-initial-concept.png` — סקיצה מוקדמת להשראה בלבד. התמונה שבה אינה לשימוש.

### assets/backgrounds

- `monogram-line-background.png` — רקע רחב ונקי המבוסס על קו הלוגו.

### docs

- `CLAUDE-CODE-PROMPT-HE.md` — הפרומפט המלא לבנייה.
- `DESIGN-TOKENS.css` — משתני הצבע, הטיפוגרפיה והריווח.

## סדר עדיפויות לקלוד

1. הלוגו והתמונה המקוריים הם המקור המחייב.
2. `homepage-with-barry.png` הוא הכיוון המרכזי לעמוד הבית.
3. `design-system-board.png` מגדיר את מערכת הרכיבים והצבעים.
4. יתר הסקיצות הן דוגמאות לשימושים משתנים בשפה.

## כלל חשוב

האתר לא צריך להעתיק טקסט מתוך התמונות. יש לבנות את כל הכותרות, הכפתורים והרכיבים כ-HTML נגיש ורספונסיבי.
